# Publicação do catálogo portátil

Esta pasta já contém o site pronto e `assets/` com imagens, vídeo, logo, áudio e demais mídias. Mantenha todos os arquivos juntos.

## GitHub Pages

Envie o conteúdo desta pasta para a raiz de um repositório. Em **Settings → Pages**, selecione **Deploy from a branch**, escolha `main` e a pasta **`/ (root)`**. O endereço será `https://USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Vercel

Importe o repositório que contém estes arquivos na raiz ou faça upload da pasta inteira. O `vercel.json` já contém o fallback para o `index.html`.

## Outras hospedagens

Netlify, Cloudflare Pages e hospedagens de arquivos estáticos também funcionam: envie o conteúdo desta pasta para a pasta pública.

## Atenção comercial

Atualize preço, estoque e condições antes de publicar. Confirme autorização para usar comercialmente marcas, imagens, logotipo, vídeo e áudio.
